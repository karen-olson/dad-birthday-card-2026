# Dad’s birthday crossword

A static birthday-card site: solve the crossword to unlock a short note.

**Live site (after GitHub Pages is enabled):**
[https://karen-olson.github.io/dad-birthday-card-2026/](https://karen-olson.github.io/dad-birthday-card-2026/)

## One-time GitHub Pages setup

1. Merge this branch into `main`.
2. Open **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.
4. The `Deploy to GitHub Pages` workflow will publish the site on the next push to `main` (or run it manually from the **Actions** tab).

The card is public on the internet once Pages is on, so share the link only with people you want to see it.
